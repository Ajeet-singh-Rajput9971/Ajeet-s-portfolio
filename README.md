# 🌐 Personal Portfolio

A modern, responsive personal portfolio website showcasing my skills, projects, experience, and contact information. Built to highlight my work and provide an easy way for recruiters, clients, and collaborators to connect with me.

## ✨ Features

* Responsive design for desktop, tablet, and mobile
* Modern and clean user interface
* About Me section
* Skills showcase
* Resume download
* Contact form
* Social media integration

## 🛠️ Tech Stack

* **Frontend:** HTML, CSS, JavaScript.
* **Styling:** CSS 
* **Deployment:** GitHub Pages
